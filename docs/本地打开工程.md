# 在本地打开这个工程

这个工程有两条完全独立的路径，先确认你要哪条：

| 你要做什么 | 需要的东西 | 要不要 LVGL 源码 |
|---|---|---|
| 烧到板子上跑 | VS Code + PlatformIO | **不需要** |
| 在电脑上看界面、改 UI | CMake + SDL2 + LVGL | 需要（脚本自动下） |

烧录只需要 `src/` + `platformio.ini`；`sim/`、`third_party/`、`build/` 只服务于电脑上的模拟器，不参与固件编译。

---

## 一、把工程拿到本地

下载 `esp32_radar_fw.zip`，解压。**放在纯英文路径下**（例如 `D:\work\esp32_radar_fw`），中文路径会让 PlatformIO 和 CMake 在某些环节出错。

解压后目录长这样：

```
esp32_radar_fw/
├── src/                 固件源码（UI / 数据 / 网络 / 硬件移植层）
├── device/lv_conf.h     设备端 LVGL 配置
├── sim/lv_conf.h        模拟器端 LVGL 配置
├── platformio.ini       烧录配置
├── CMakeLists.txt       模拟器构建脚本
├── scripts/             下载 LVGL 的脚本
├── docs/                文档
└── preview/             界面截图
```

---

## 二、只烧硬件（最短路径）

**1. 装 VS Code + PlatformIO 插件**

VS Code 扩展商店搜 `PlatformIO IDE`，装上后它会自动下载 Python、xtensa 工具链（第一次约 500MB，等它跑完）。

**2. 拉微雪官方库**（屏幕 CO5300 / 触摸 / 引脚定义都在这）

在工程根目录开终端：

```bash
git clone --depth 1 https://github.com/waveshareteam/ESP32-S3-Touch-AMOLED-2.16 vendor/waveshare-demo
```

> 如果你下的是 **完整版 zip**（`esp32_radar_fw_full.zip`），`vendor/` 已经内置，这一步可以跳过。

**3. 插线烧**

```bash
pio run -t upload
pio device monitor
```

板子只有一个 USB-C 口，直连 ESP32-S3 原生 USB，Win10/11 免驱。卡在 `Connecting...` 就按住 **BOOT** 再插线。

详细步骤和故障对照见 [到货烧录指南.md](到货烧录指南.md)。

## 三、在电脑上跑模拟器（看界面）

模拟器就是一块 480×480 的虚拟屏幕，跑的是**同一份 UI 代码**。`src/ui/` 改完，电脑上立刻能看到，不用每次烧板子。

### 推荐：WSL2（Windows）/ macOS / Linux

三个平台命令基本一致，和云端环境完全一样。

**Ubuntu / WSL2 / Debian**

```bash
sudo apt update
sudo apt install -y cmake build-essential libsdl2-dev
```

**macOS**

```bash
brew install cmake sdl2
```

**然后（三个平台相同）**

```bash
cd esp32_radar_fw
# 完整版 zip 已内置 LVGL，跳过下一行
bash scripts/setup_lvgl.sh                      # 仅精简版需要：下载 LVGL 9.3.0 到 third_party/lvgl
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
./build/sim
```

第一次编译 LVGL 全量源码，`-j` 开满核大约 1~3 分钟；之后改 UI 只重编 `src/ui/` 那几个文件，几秒钟。

> **WSL2 弹不出窗口**：需要 WSLg（Win11 自带；Win10 需 21H2 + 手动装）。如果报 `Failed to open display`，装个 VcXsrv 然后 `export DISPLAY=:0`。搞不定就直接在 Windows 原生环境跑（见下）。

### Windows 原生（MSYS2）

不想用 WSL 的话：

1. 装 [MSYS2](https://www.msys2.org/)，打开 **MSYS2 MINGW64** 终端
2. ```bash
   pacman -S mingw-w64-x86_64-gcc mingw-w64-x86_64-cmake mingw-w64-x86_64-SDL2 make git
   ```
3. 在同一个终端里进工程目录，跑：
   ```bash
   bash scripts/setup_lvgl.sh
   cmake -S . -B build -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release
   cmake --build build -j
   ./build/sim.exe
   ```

（Visual Studio 自带的 MSVC 也能编，但 SDL2 得自己配，不建议折腾。）

### 想直接看某一页

模拟器支持几个环境变量，省得用手势翻页：

```bash
START_PAGE=0 ./build/sim      # 0=雷达 1=时钟天气
START_PAGE=1 ./build/sim
OPEN_TARGET=1 ./build/sim     # 启动即弹出某个航班的详情卡
RADAR_SRC=0 ./build/sim       # 强制演示航班（不联网）
DEBUG_CYCLE=4000 ./build/sim  # 每 4 秒自动切页，看整体动效
```

Windows 下同理：`set START_PAGE=1` 再 `.\build\sim.exe`。

**操作**：鼠标拖动或方向键切页；雷达页点击目标弹详情卡，点空白关闭。

## 四、改哪里

| 想改什么 | 改这个文件 |
|---|---|
| 雷达配色、扫描速度、字体 | `src/ui/ui_theme.h`、`src/ui/ui_radar.c` |
| 时钟天气排版、图标 | `src/ui/ui_clock_weather.c` |
| 模拟数据 / 经纬度换算 | `src/data/data_flight.c` |
| 接真实航班接口 | `src/data/data_flight_net.c` |
| 天气接口 | `src/data/data_weather.c` |
| 手机配网页面 | `src/net/web_config.cpp` |
| 屏幕/触摸驱动 | `src/port/port_esp32.cpp` |
| 中文用到的字 | `src/ui/cn_font.c`（用 lv_font_conv 重新生成） |

**两处 `lv_conf.h` 不要搞混**：

- `device/lv_conf.h` → 给 ESP32 用，靠 `platformio.ini` 的 `-I device` 生效
- `sim/lv_conf.h` → 给电脑模拟器用，靠 CMake 的 `-DLV_CONF_PATH` 生效

改字号、开新字体时**两边都要改**，否则会出现「电脑上正常、烧到板子上字没了」。

改完 UI 想烧到板子：

```bash
pio run -t upload
```

## 五、常见报错

| 报错 | 原因与处理 |
|---|---|
| `找不到 LVGL：.../third_party/lvgl` | 没跑 `bash scripts/setup_lvgl.sh` |
| `Could NOT find SDL2` | 没装 SDL2：`sudo apt install libsdl2-dev` / `brew install sdl2` |
| `undefined reference to lv_font_montserrat_48` | `sim/lv_conf.h` 没生效，检查 CMake 配置输出里 `lv_conf:` 那行路径对不对 |
| 窗口黑屏 / 一闪就退 | 多半是没有图形界面环境（纯 SSH）。需要本地桌面或 WSLg |
| PlatformIO 报 `pin_config.h: No such file` | 没拉 `vendor/waveshare-demo`，或 `platformio.ini` 里 `-I vendor/.../Mylibrary` 那行被删了 |
| 中文全是方框 | `cn_font.c` 里没有这个字的字形，需要重新生成字体 |
| 屏幕方向反了 / 触摸点不准 | 改 `src/port/port_esp32.cpp` 里的 MADCTL 参数或 `setMirrorXY` |

## 六、这个工程不包含什么

- **LVGL 源码**：体积太大（158MB），由脚本按需下载到 `third_party/`，已在 `.gitignore` 里忽略。
- **编译产物**：`build/` 目录。
- **微雪官方库**：`vendor/waveshare-demo`，一条 `git clone` 拉下来。
- **真机驱动验证**：AMOLED、触摸、音频、PSRAM 这些在电脑上模拟不了，必须上板子验证。见 [到货烧录指南.md](到货烧录指南.md) 末尾的「到货后要现场确认的三件事」。
